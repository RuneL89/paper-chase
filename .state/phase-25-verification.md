## 4. Live-fix verification (2026-08-27 fixes)

**(a) Basename source-echo normalization** (`validateDisambiguationVerdict`, `src/agents/disambiguation.ts` ~258-341): a member source echo valid when it exactly equals a proposal file OR equals that file's basename; the basename map is built ONLY from basenames unique among the proposal's files (`basenameCounts === 1`) — **ambiguous basenames are deliberately NOT normalized** (they keep the error); the normalized verdict members carry the **canonical full-path form**, which is what the sticky sourceMap and later routing consume (materializer builds `sourceMap` from `member.sources` post-normalization); a member naming the same file twice (full path + basename) dedupes. Regression legs in gate 25.2 (test 536) cover canonicalization, double-mapping rejection, and unknown-echo rejection. **Verified as contracted.** Minor observation (#2): no explicit test leg for the ambiguous-basename guard itself (code path exists, untested).
