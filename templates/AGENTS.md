## Ingest Instructions for the LLM

When processing a chunk of PDF text:

1. **Extract all entities** — people, companies, organizations, locations, products, and other named things.
2. **Extract all relationships** — how entities connect to each other (e.g., "is-CEO-of", "donated-to", "owns").
3. **Extract all claims** — factual assertions with numbers, dates, and evidence.
4. **Extract a timeline** — chronological events with dates and entity references.
5. **Write a context paragraph** — describe the broader narrative this chunk belongs to.
6. **Assign folders** — place each entity in the most specific sub-folder under `entities/` or `topics/`. Create new sub-folders only when no existing folder fits.
7. **Cite everything** — use `[^srcN]` for every factual claim.

## Page Frontmatter

Every content page carries YAML frontmatter. Required fields: `title`, `type`, `updated`, and a `sources` list that maps every citation key to an exact PDF location.

```yaml
---
title: "John Smith"
type: entity
wiki: {{SLUG}}
updated: "2026-07-17T10:00:00Z"
sources:
  - file: "wikis/{{SLUG}}/raw/annual-report-2024.pdf"
    pages: "1-5, 47-48"
---
```

- `file` and `pages` are required on every `sources` entry; `extracted`, `sha256`, and `label` are optional.
- Citation keys are local to the page: `src1` on one page does not have to mean the same source as `src1` on another.
- **Wikilinks use Obsidian's native pipe form**: `[[<file-basename>|<Page Title>]]` for content pages (e.g. `[[john-smith|John Smith]]`), `[[<folder-path>/index|<Folder Title>]]` for folder indexes (e.g. `[[entities/people/index|People]]`), and `[[index|<Wiki Title>]]` for the wiki root. Use the bare form `[[name]]` only when the display text is identical to the target.
- Optional `aliases: [<title>]` is added when the page title differs from the file basename (case-insensitive); index pages always carry their folder/wiki title as the alias. Aliases remain as Obsidian search/suggester aids — they are not the link-resolution mechanism. Omit the field when title and basename match.

## Entity Page Format

Every entity, topic, and document page must have two layers:

**Layer 1 — Synthesis (top of page):**
- 2-4 paragraphs of readable prose telling the entity's story.
- Include chronological context with explicit dates, cross-references to the broader story, and significance.
- **Disambiguation** — if the name is ambiguous, clarify which entity this page is about (and which it is not).
- Every factual claim must have a citation `[^srcN]`.

**Layer 2 — Preserved Detail (below synthesis):**
- `## Mentions` — every mention with exact quote, page number, and citation.
- `## Relationships` — every relationship with evidence and citation.
- `## Claims` — every claim organized by type, with citation.
- `## Timeline` — chronological events involving this entity, with citations.
- `## Sources` — all source definitions `[^srcN]: filename.pdf, pages X-Y` (mirroring the frontmatter `sources`).

## Citation Rules

- **Every factual claim** uses an inline citation: `[^srcN]` — numbers, dates, names, direct quotes, assertions of fact.
- **Source definitions** appear in the `## Sources` section (`[^srcN]: filename.pdf, pages X-Y`) for readers, and machine-readably in the page's `sources` frontmatter.
- **Multiple claims** from the same source range **reuse the same key**; a single claim supported by multiple sources carries multiple keys.
- **Synthesis framing** (e.g., "This section discusses...") does not require a citation.
- **Derived conclusions** and factual assertions **always** require a citation.
- **When a page is updated**, all existing citations are preserved; new evidence gets new citations, re-numbered if needed to stay sequential.

## Writing Rules

- **The Journalist Test** — a reader who has never seen the original PDFs must be able to explain this entity to a colleague, cite three facts with sources, and name two related entities. If a page fails this test, it is not done.
- Write in clear, plain language suitable for an investigative journalist.
- Do not drop any extracted detail. Every mention, relationship, and claim must appear on the page.
- Never invent facts, sources, page numbers, or quotes.
- Use `[[<file-basename>|<Page Title>]]` wikilinks (Obsidian-native pipe form) for related entities and topics.
- Preserve existing citations and human-written edits when updating a page.
- When uncertain about folder assignment, prefer the most specific existing folder.
- If no existing folder fits, create a new sub-folder and explain why in your output.
