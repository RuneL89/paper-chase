**Defect A — wiki root is a dead-end hub.** The prompt (`prompts/dox-writer.prompt.txt:70`) asks the root for only a curated `## Start Here` (3–6 picks) and explicitly forbids a Navigation section; the wiki-level example (lines 147–176) models linking *past* the children to deep folders. The validator (`missingRequiredSections`, `src/dox-writer.ts:430`) only requires `## Start Here` + `## Statistics` at root — so the omission passes. Vision `03` §4.2 already requires a Catalog of pages/sub-folders in **every** index.md; only the §4.3 example contradicts it.

**Defect B — 9 single-page topic indexes self-link.** Their `## Pages` bullet links `[[topics/<slug>/index|…]]` (their own index — circular) instead of `[[<slug>|…]]` (the real page), making 9 content pages unreachable via the index chain. The enforcement only checks section *presence*; `repairWikilinks` only fixes *unresolvable* links — and a self-link resolves, so nothing catches it. No deterministic check verifies that supplied catalog links actually appear in the body.
