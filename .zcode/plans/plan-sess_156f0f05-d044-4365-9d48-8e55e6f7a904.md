Add a `--force-cross-wiki` CLI flag and a TUI toggle that bypass the Phase 24 preflight/probe and always run the cross-wiki discovery pass when ≥2 wikis exist.

### Plan

1. **Core option plumbing**
   - `src/commands/ingest.ts`: add `forceCrossWiki?: boolean` to `IngestOptions` next to the existing `crossWiki` option. Pass it through to `runCrossWikiPass`.
   - `src/cross-wiki/index.ts`: add `forceCrossWiki?: boolean` to `CrossWikiPassOptions`. In `runCrossWikiPass`, after computing the run fingerprint, if `forceCrossWiki` is true and the workspace has ≥2 wikis, override the preflight decision with `{ action: 'run', reason: 'forced' }` so Components A–G run. The fingerprint is still written at the end like a normal run.

2. **CLI flag**
   - `src/cli.ts`: add `.option('--force-cross-wiki', 'Force the Phase 24 cross-wiki discovery pass to run')` to the `ingest` command and forward `forceCrossWiki: options.forceCrossWiki` to `ingest()`.
   - Keep `--no-cross-wiki` as the master off switch: if a user passes both `--no-cross-wiki` and `--force-cross-wiki`, the cross-wiki block is simply skipped (no conflict resolution needed).

3. **TUI toggle**
   - `src/tui/ingest-screen.tsx`:
     - Add `forceCrossWiki` state, default `false`.
     - Toggle it with `f`/`F`.
     - Add a third checkbox row: `[ ] Force Cross-Wiki Discovery (F to toggle)`.
     - Update the footer help text to include `F: force cross-wiki`.
     - Pass `forceCrossWiki` into the `ingest()` call.

4. **Tests**
   - `tests/phase-24.test.ts`: add a gate that injects `runCrossWikiPassFn` and verifies it is called with `forceCrossWiki: true` when the ingest option is set, and that the pass runs even when the preflight would otherwise skip.
   - `tests/phase-11.test.ts` / `tests/tui/menu.test.tsx`: update any assertions that match the ingest-screen footer/help text to include the new `F` binding.
   - Run `npm test` and `npx tsc --noEmit` before finishing.

5. **DOX / docs**
   - `src/AGENTS.md`: update the cross-wiki call contract to document the `forceCrossWiki` option.
   - `README.md`: add `--force-cross-wiki` to the CLI examples and mention the TUI `F` toggle in the Phase 24 / walkthrough sections.
   - `.state/compliance-log.md`: add an entry documenting the user-directed `--force-cross-wiki` extension.

6. **Packaging**
   - This touches `src/cli.ts` and `src/tui/ingest-screen.tsx`, both in the bundled app. Rebuild `dist/paper-chase.exe` (`npm run package:win`) and bump the launcher asset version in `scripts/launcher-entry.ts` so the packaged runtime re-extracts the updated bundle.
