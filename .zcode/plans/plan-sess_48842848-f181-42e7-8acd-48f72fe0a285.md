# Icon for paper-chase.exe — paper-stack→wiki, terminal green, rounded plate

## Design (locked with user)
Rounded-square dark charcoal plate; fanned 3-sheet paper stack; top sheet carries a phosphor-green wiki link-graph (nodes + edges). Bold flat shapes that survive 16px.

## Steps

1. **Author `assets/icon.svg`** — new `assets/` folder. Charcoal plate (~#1c211c), phosphor-green glyph (~#3dff7c). Sheets as offset rounded rects; top sheet with 3–4 thick-stroked nodes/edges. Designed at 512 with an oversized-stroke small-size variant if needed for 16px legibility.
2. **Icon tooling (devDeps)** — add `@electron/rcedit` (patches the PE resource), `sharp` (SVG→PNG), `png-to-ico` (PNGs→.ico). All have Windows prebuilts.
3. **`scripts/build-icon.ts`** — SVG → PNGs at 256/128/64/48/32/24/16 → `assets/icon.ico` (multi-size). Regenerable; the .ico/.svg are committed.
4. **`scripts/set-icon.ts`** — runs rcedit `dist/paper-chase.exe --set-icon assets/icon.ico`; fails loudly if the exe is missing.
5. **`package.json`** — `package:win` gains `&& tsx scripts/set-icon.ts` after the pkg stage. `package:win:raw` untouched (debug-only). Scope stays **paper-chase.exe only** — runtime-node.exe is NOT iconized (it's re-copied from the build machine's node.exe each build and lives hidden in %LOCALAPPDATA%).
6. **Approval loop (before wiring)** — render a 512px preview + a 16/32px legibility strip, show them to the user, iterate the SVG until approved. Only then generate the .ico and touch the build.
7. **Rebuild + verify** — `npm run package:win` (VERSION bump NOT needed — a PE icon is not a snapshot asset, so the runtime marker/extract logic is unaffected; confirmed in exploration). Verify rcedit exit 0 and the icon shows in Explorer. The rebuilt exe gets committed via the existing Git LFS flow, as with every rebuild.
8. **DOX pass** — new `assets/AGENTS.md` (purpose: build icon assets; rule: regenerate via `scripts/build-icon.ts`); root AGENTS.md gains the `assets/` Child DOX Index entry and the `dist/` special-case build-steps line gains the post-pkg rcedit step; compliance-log entry per project convention.

## Out of scope
runtime-node.exe and paper-chase-raw.exe icons; shortcut/installer icons (none exist); macOS/Linux assets.
