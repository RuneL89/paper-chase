# prompts/ — DOX contract

## Purpose

LLM prompt files for the agent pipeline (Extractor, Synthesis Writer, DOX Writer, AGENTS.md Updater, Curation agent, Cross-Wiki Discovery). The Extractor prompt landed with Phase 2, the Synthesis Writer prompts with Phase 5, the DOX Writer prompt with Phase 6, the AGENTS.md Updater prompt with Phase 9, the Curation prompts with Phase 14, the composite synthesis prompts with Phase 22, the comparison synthesis prompt with Phase 23, and the seven cross-wiki discovery prompts with Phase 24.

## Ownership

* `extractor.prompt.txt` — Phase 2: the Extractor's prompt. Fixed system instructions (8 extraction rules, entity page format, citation format per phase doc §2.1) + an explicit JSON-only OUTPUT FORMAT section (exact schema incl. the gates-2.9–2.12 extended fields `timeline`, `context`, `significance`, `disambiguation`) + runtime placeholders `{agentsMd}`, `{existingFolders}`, `{existingEntities}`, `{sourceFile}`, `{pageRange}`, `{chunkText}` substituted by `src/agents/extractor.ts`; Phase 13 closeout (user-ratified 2026-07-24): the entity page-format line is floor-free — Layer 1 is quality-sized by the evidence, no "2-4 paragraphs" minimum; Phase 23 (§2.1, backlog B21): the output gains the `tables` array — generic wording ("structured tables comparing multiple subjects (e.g., regions, organizations, periods) against shared measures"), `subject` (the entity the table is ABOUT — the existing-entities slug when resolvable), `title` (the table's own caption), `page` (within `{pageRange}`), `rowDimension`/`colDimension`, `entities`, `markdown` (the extractor RECONSTRUCTS the text-table — structure the extractor's, every row label and value the document's own, verbatim), `summary`; the top-level field list and the empty-chunk rule name it; nothing RKKP/registry-specific

Phase 13 (phase doc §2.2, user-ratified 2026-07-23): the old word-count rule bullet is REMOVED and the ratified self-sizing block ("Length is not a target — completeness is. …") closes the rules list in its place — length is set by the evidence, never a target (the byte-exact block text is asserted in `tests/phase-13.test.ts`); Phase 13 closeout (user-ratified 2026-07-24): the Layer-1 format line's "2-4 paragraphs" floor is also removed — Layer 1 is quality-sized (several paragraphs rich / a few honest sentences thin), completing the self-sizing doctrine inside the same file); Phase 17 (B12a, vision `02` §2; slot-additive only — every pre-existing section byte-identical, hash-pinned by gate 17.6): the ENTITY DATA section gains the `{relatedEntities}` slot ("Related Entities (the only legal wikilink targets — slug — title)") and the wikilink rule now requires targets to come from that list with first-mention linking in Layer 1; Explains the DOX Writer role (map, not territory) and the bottom-up flow (deepest folders indexed first; child folder indexes supplied to parents), defines two writing modes — (a) PAGES mode (folders with direct pages summarize those pages) and (b) SYNTHESIS mode (folders with child folders synthesize the child contracts into a parent-level description; both modes when a folder has pages AND children) — gives the exact output format (YAML frontmatter + body: title heading, rich description, `## Pages` + `## Navigation` for folders or `## Start Here` + a complete child-folder `## Pages` catalog for the root — 2026-07-25 navigation fix: Start Here stays the curated shortlist while `## Pages` catalogs EVERY child folder, so the whole wiki is reachable via the parent/child index chain, `## Statistics`), requires `## Pages` to catalog direct pages AND child folders (a zero-page parent still catalogs its child folders rather than emitting "No pages"; Phase 13 §2.3 adds the catalog-line quality rule — each `## Pages` line must tell the reader something the page title alone does not; the 2026-07-25 navigation fix adds the completeness/self-link rule — every supplied page and child folder must appear with its exact supplied link form, a page entry links the PAGE never the folder's own index, an index never links to itself), instructs verbatim use of the supplied children list, statistics, and EXACT LINK TARGETS (Obsidian-native pipe forms guaranteed to resolve by pure file lookup: `[[basename|Title]]` for pages, `[[<folder-path>/index|Title]]` for folder indexes, `[[index|Wiki Title]]` for the root — 2026-07-20 user-directed change), requires following the supplied wiki AGENTS.md writing rules (plain language, journalist test, no invented facts), and shows one pages-mode folder example, one synthesis-mode zero-page-parent example, and one wiki-level example (Start Here + complete `## Pages` catalog since the 2026-07-25 fix; phase doc §3.3/§3.4). Deterministic enforcement in `src/dox-writer.ts` always discards the returned frontmatter, replaces the `## Statistics` section, verifies catalog completeness (every supplied page/child-index link target present; no self-referential index links — violations join the missing-section feedback of the Phase 12 reask loop), and normalizes/repairs/de-links wikilinks that are not already canonical pipe forms, so the prompt's prose quality matters but its frontmatter/counts/link forms are never blindly trusted

## Local Contracts

* One prompt file per agent role, named `<agent>.prompt.txt`, created only by its implementing phase per the phase document
* Prompts are read by code in `src/`; keep them free of secrets and environment specifics
* Runtime placeholders use `{single-brace}` names (phase doc convention) — distinct from the `{{DOUBLE_BRACE}}` init-time placeholders in `templates/`; every placeholder must be substituted by the owning agent code before the call
* Phase 7 `{languageDirective}` contract (vision `04` §9.4): all eleven agent prompts (extractor, both entity synthesis, both topic synthesis, dox-writer, both Phase 14 curation prompts, both Phase 22 composite synthesis prompts, the Phase 23 comparison prompt) carry a `=== LANGUAGE ===\n{languageDirective}\n\n` block near the top, filled by the owning agent via `applyLanguageDirective` in `src/utils/language.ts` — non-empty directive replaces the placeholder; empty directive (both languages English) removes the WHOLE block so filled prompts stay byte-identical to pre-Phase-7. The curation directive (vision `04` §9.4): identities are judged in the wiki's OUTPUT language while the sample claim/mention texts stay verbatim source evidence (a translation of the same name is still the same thing — a merge signal, not a difference). The workspace prompt (`dox-writer-workspace.prompt.txt`) does NOT carry it — it has its own `{outputLanguage}` placeholder per the 2026-07-20 amendment. Phase 24: the seven cross-wiki discovery prompts carry the same block, filled with the additive `cross-wiki` role directive (prose fields in the run's output language; names, aliases, and quoted evidence verbatim; cross-language comparison is the pass's design default per user decision #5)
* Prompt text must keep instructing: JSON-only output, folders only under `entities/`/`topics/` (max 3 levels below), lowercase kebab-case slugs, page numbers within the given range, empty chunk → empty arrays, and reuse of existing folders/entities from rolling memory — the Phase 2 gates depend on these behaviors
