# src/ — DOX contract

## Purpose

All TypeScript source for Paper Chase v.1.0: CLI entry point, TUI (Ink), PDF extraction, LLM client, the Extractor agent (Layer 2), the Synthesis Writer (Layer 4), the deterministic Materializer (Layer 3), the DOX Writer (Layer 5), the AGENTS.md Updater, schema validation, commands, state, and utilities.

## Local Contracts

* Phase 0 public surface is frozen per `Implementation Plan/PHASE_00_infrastructure.md` §7: `extractText`, `callLLM`, `sha256`, and the TUI framework must not change signature/behavior after Phase 0 approval; later phases extend, they do not break (Phase 1's `getPageCount` and Phase 2's `CallLLMOptions` are additive extensions with identical defaults)

* LLM calls in the pipeline (all via `callLLM`, all logged): the Extractor (Layer 2, per chunk), the Synthesis Writer (Layer 4, opt-in Phase 5), the DOX Writer (Layer 5, Phase 6 `doxLlm` mode, per folder plus the wiki root, plus one workspace-pass call per ingest for `wikis/index-of-indexes.md`), and the AGENTS.md Updater (Phase 9, opt-in `updateAgents`, one call per ingest); every other concern (folder creation, page writing, memory updates) is deterministic code
* Four-class retry policy (vision `04` §6, feedback-retry carve-out user-ratified 2026-07-23, implemented in Phase 12; binding for every pipeline LLM call): (1) **deterministic** failures — HTTP 4xx — are NEVER retried (`callLLM` throws immediately); (2) **transient** transport failures (429/5xx/network) retry inside `callLLM` with linear backoff (`maxRetries`; unchanged by Phase 12); (3) **content-defect** failures — invalid Extractor JSON, Extractor schema issues — re-ask ≤3 total attempts via `llm/reask.ts` with the validator's exact errors fed back, and Extractor exhaustion aborts the ingest fail-loud; (4) **quality** failures — synthesis preservation, DOX/workspace missing-section/unparseable/empty output, updater missing-section/too-short proposals — use the same feedback-retry loop before their deterministic fallbacks, and a THROWN error at those sites is caught ONCE per target (never quality-retried). Every repair is logged with the `<ctx>#attempt<N>` context, counted in `metrics.feedbackRepairs`, and a prompt-quality warning fires at ≥5 repairs in a run or >25% of the run's LLM calls
* Page types are declared in frontmatter; known built-in types are `entity`, `topic`, `document`, `source`, `raw`, and `index` (added in Phase 6)
* Wikilink form contract (user directive 2026-07-20, superseding the bare title-form convention; compliance-log entry [2026-07-20 00:15]): every wikilink the CLI writes uses Obsidian's native target-plus-display pipe form — content pages `[[<basename-without-.md>|<Title>]]` (basename only, no folder path), folder indexes `[[<folder-path>/index|<Title>]]`, wiki root `[[index|<Wiki Title>]]`, bare `[[target]]` only when display equals the target exactly.
